    Session 7 · Selection and Shrinkage: How Short Can the Form Be?¶

    So far our poverty model uses 19 variables: 19 questions a social worker must ask, record and verify in every household visit.

    Today's question. Every question costs interview time, can be gamed by applicants, and must be checked. Which variables do we really need? A shorter form that predicts almost as well is a policy win.

    What is new today: forward stepwise selection, penalised logistic regression (Ridge, LASSO, Elastic Net), the penalty strength C = 1/λ, the regularisation path, and choosing the penalty by cross-validation.

    1. The preprocessing, as a function of which questions we keep¶

    Same rules as Session 5, but now the list of columns changes from model to model, so we wrap the ColumnTransformer in a small function.

    def preprocessor(cols):
    """The Session 5 preprocessing, restricted to the columns in `cols`."""
    num, hours, cat = [c for c in cols if c in NUM], [c for c in cols if c in HOURS], [c for c in cols if c in CAT]
    parts = []
    if num:
        parts.append(("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num))
    if hours:
        parts.append(("hours", make_pipeline(SimpleImputer(strategy="constant", fill_value=0), StandardScaler()), hours))
    if cat:
        parts.append(("cat", make_pipeline(SimpleImputer(strategy="constant", fill_value="missing"),
                                           OneHotEncoder(handle_unknown="ignore")), cat))
    return ColumnTransformer(parts)


def cv_auc(model, cols):
    s = cross_val_score(model, X_train[cols], y_train, cv=cv, scoring="roc_auc", n_jobs=-1)
    return s.mean(), s.std()

    2. Forward stepwise selection: build the form one question at a time¶

    Best subset selection would try every possible form: with 19 questions that is 2¹⁹ ≈ 524,000 models. Forward stepwise is the greedy shortcut: start with no questions; at each step add the one question that raises the cross-validated AUC the most.

    We select questions (raw variables), not dummy columns: a form cannot ask "region = Maule?" without asking the region. scikit-learn's SequentialFeatureSelector works on the columns of the final matrix (the dummies), so we write the loop ourselves, with one pipeline per candidate set. It takes about a minute.

    3. Penalised regression: shrink instead of choosing¶

    Selection is all-or-nothing. Shrinkage keeps every variable but adds a price for large coefficients to the quantity the model minimises:

    $$\text{log-loss}(\beta) + \lambda \cdot \text{penalty}(\beta)$$

    Method Penalty Effect
    Ridge (L2) $\sum_j \beta_j^2$ shrinks all coefficients towards 0, none exactly 0
    LASSO (L1) $\sum_j \lvert\beta_j\rvert$ shrinks, and sets some coefficients exactly to 0
    Elastic Net a mix of both sparse like LASSO, more stable with correlated variables

    In scikit-learn the strength is C = 1/λ: small C = strong penalty. Because the penalty compares coefficients with each other, all variables must be on the same scale, which is why the StandardScaler stays in the pipeline.

    ⚠️ scikit-learn's LogisticRegression() is already Ridge with C = 1 by default. The Session 5 model was slightly penalised all along. Econometrics software (Stata, statsmodels) does not penalise by default.

    A version trap¶

    scikit-learn 1.8 changed how you ask for LASSO: penalty="l1" became l1_ratio=1. Older versions, still common on Colab, silently ignore l1_ratio unless penalty="elasticnet", and so fit a Ridge without telling you. This helper works on both:

    NEW_API = tuple(int(p) for p in sklearn.__version__.split(".")[:2]) >= (1, 8)
print("scikit-learn", sklearn.__version__, "| new penalty API:", NEW_API)


def penalised_logit(C, l1_ratio):
    """l1_ratio = 0 -> Ridge, 1 -> LASSO, in between -> Elastic Net."""
    solver = "liblinear" if l1_ratio in (0, 1) else "saga"
    if NEW_API:
        return LogisticRegression(C=C, l1_ratio=l1_ratio, solver=solver, max_iter=5000, random_state=0)
    penalty = {0: "l2", 1: "l1"}.get(l1_ratio, "elasticnet")
    extra = {"l1_ratio": l1_ratio} if penalty == "elasticnet" else {}
    return LogisticRegression(C=C, penalty=penalty, solver=solver, max_iter=5000, random_state=0, **extra)

    4. The LASSO path: from no variables to all of them¶

    We fit the LASSO for 40 values of C, from a very strong penalty (C = 0.001) to a weak one (C = 10), and record the coefficients, the CV AUC, and how many questions still have at least one non-zero coefficient.

    def question_of(feature):
    body = feature.split("__", 1)[1]
    return next(v for v in RAW if body == v or body.startswith(v + "_"))


Cs = np.logspace(-3, 1, 40)
rows, coefs = [], []
for C in Cs:
    model = Pipeline([("pre", preprocessor(RAW)), ("clf", penalised_logit(C, 1))])

    6. When does shrinkage pay off? When data is scarce¶

    Imagine a pilot survey in one province: a few hundred households, the same 76 columns. We train on random subsamples of the training set and evaluate on the (full) test set.

    def test_auc(model, Xs, ys):
    return roc_auc_score(y_test, model.fit(Xs, ys).predict_proba(X_test)[:, 1])

    return max(grid, key=lambda C: cross_val_score(
        Pipeline([("pre", preprocessor(RAW)), ("clf", penalised_logit(C, l1_ratio))]),
